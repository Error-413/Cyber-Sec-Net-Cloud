# Cyber-Sec-Net-Cloud

Ce projet combine la cybersécurité, la gestion des réseaux et le cloud. Il contient des scripts pour sécuriser un réseau, configurer un cloud et implémenter des stratégies de sécurité.

## Structure du projet
- `src/` : Code source pour la gestion du réseau, du cloud et de la sécurité.
- `config/` : Fichiers de configuration pour le réseau et le cloud.
